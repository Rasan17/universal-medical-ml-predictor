🔬 Strictly Ordered 7-Step Clinical ML Pipeline

End-to-end leak-free clinical ML protocol: 80/20 train/test split with strict training-only imputation, normality & correlation testing (Pearson vs Spearman), VIF multicollinearity elimination, univariate baselines, SMOTENC balancing, Random Forest feature scout, and algorithm-constrained final evaluation.

Step 2: Continuous Variable Correlation Check (Pearson vs. Spearman)
Continuous variables in the Training set are evaluated for normality via skewness within [-1, 1]. Pearson (r) is calculated when both variables are normal; Spearman (ρ) is calculated if one or both are skewed. High-collinearity pairs (|r| or |ρ| ≥ 0.8) are presented below to allow dropping one or keeping both.

Step 3: Variance Inflation Factor (VIF) Check
Categorical variables are one-hot encoded (dropping reference category to eliminate dummy trap) and continuous variables standardized. VIF is computed for all surviving features. Features with VIF > 5 indicate severe multicollinearity and can be permanently eliminated from both Train and Test sets.

Features Multicollinearity Table (VIF & R²)

VIF > 5 indicates high multicollinearity ($R^2 > 0.80$). Check variables to drop and click 'Drop Selected Features'.

🧪
Step 4: Univariate Statistical Testing Check
Informational baseline testing of surviving original variables against the Target: One-Way ANOVA (or t-test) for continuous features and Pearson Chi-Square (χ²) for categorical features. Variables are sorted from lowest p-value to highest. Variables are NOT automatically dropped at this step.

📑 Univariate Statistical Screening Baseline (Sorted by p-value Ascending)

Select which predictor variables to include or exclude based on statistical significance or clinical judgment before balancing & model training.

ℹ️ You can exclude non-significant predictors or keep all variables for multivariate training.
⚖️
Step 5: Imbalance Handling (SMOTENC)
Evaluates target variable distribution strictly in the Training set. If the minority class represents < 30% of the training cohort, SMOTENC is applied to synthesize minority samples while preserving categorical feature indices. The Testing set is strictly NEVER resampled or altered.
Evaluating Training set class balance...
🔒 Strict Leak Prevention: Testing set remains 100% unaltered to test true clinical prevalence.
🌲
Step 6: Model-Driven Feature Ranking (Random Forest Scout)
Trains a Random Forest scout on the SMOTENC-balanced Training set. Mean Decrease in Impurity (MDI) importance scores are extracted for all surviving features. A 30% cutoff threshold is identified to prune features for dimensionality-sensitive algorithms (k-NN & Naive Bayes) in Step 7.

📊 Ranked Feature Importance (Random Forest Impurity Reduction)

Click 'Run Random Forest Scout' above to compute feature rankings.

💡 k-NN & Gaussian Naive Bayes will automatically train only on the Top 70% features.
🎯
Step 7: Algorithm-Specific Training & Constraints
Applies strict stability constraints to each algorithm:
  • k-NN & Gaussian Naive Bayes: Automatically drop bottom 30% features (combat curse of dimensionality).
  • Deep Neural Network (DNN): Enforces L2 Regularization (weight decay) + Dropout layers against overfitting.
  • Logistic / Ridge Regression: Applies L2 penalization to stabilize any remaining minor collinearity.
  • Super Learner (Ensemble): Fits StandardScaler strictly on Training set and applies to Testing set with one-hot encoding.
All models are evaluated strictly on the unaltered Testing set emphasizing clinical metrics (F1-Score, Precision, Recall, AUC-ROC, Accuracy).
